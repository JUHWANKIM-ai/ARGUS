## "구조적 측정 불가" 재검토

v3 결산이 남긴 문장: *"메타 축 나머지(`corp_name`·`rcept_dt`·`path`)는 **측정 불가**를 결론으로
기록한다 — 추정값으로 채우지 않는다"* (`v3 §LOO 확장` · `09 §I-5f ⑧` `L5` 행: *"측정 불가(절반은
이미 `A1b` 안에서 쟀다)"*).

### 판정: 🔴 **절반은 참이고 절반은 틀렸다. 방법을 못 찾은 쪽이다.**

**참인 부분** — `scripts/ablation.py:1858` 과 `Arm.__post_init__` 의 `META_UNREACHABLE_FLAGS`
검사가 옳다. `_gather_meta` 는 `retrieval == "meta"` 에서만 도달하고(`pipeline.py:1504`)
`A8` 은 그 앞을 지나가지 않으므로 **"`A8` 안에서 `A0` 구성요소를 떼어낸다"** 는 정의상 불가다.
`Arm` 에 그 flag 를 켜면 `ValueError` 가 난다 — 저장소가 그 사고를 코드로 막아 뒀다.

**틀린 부분** — 🔴 **메타 축은 `_gather_meta` 안에만 있는 것이 아니다. `A8` 의 검색 경로가
같은 축을 도구 인자로 쓰고 있다.**

```python
# pipeline.py:1567-1571  (A8 의 검색 차선)
args = {"query": plan.query, "top_k": plan.top_k, **cell}   # ← cell 이 rcept_dt(ym/year) 축이다
if group != "exchange": args["group"] = group               # ← doc_subtype 축
if corp: args["corp_name"] = corp                           # ← corp_name 축
```
```python
# tools.py:396-403  (search_chunks)
if corp_name: filters["corp_name"] = resolve_company(...)   # 완전일치 필터
if ym:   prefix["rcept_dt"] = str(ym).replace("-","")[:6]
elif year: prefix["rcept_dt"] = str(year)[:4]
# tools.py:346-350  (_search_sections)
if path: prefix["path"] = path                              # ← path 축, 정기공시
```

즉 `corp_name` · `rcept_dt` · `path` 는 **A8 안에서 살아 있는 필터 축**이고,
LOO 는 *"그 인자를 넘기지 않는다"* 로 표현된다 — `Arm` 에 플래그 하나(`meta_filters: bool`
또는 축별 3개)를 더하고 위 세 자리에서 조건부로 빼면 된다. **`_gather_meta` 를 건드리지 않으므로
`META_UNREACHABLE_FLAGS` 검사와도 충돌하지 않는다.**

**그리고 그 Δ 가 클 것이라는 사전 근거가 이미 문서에 있다:**
- `09 §I-1`·`_gather_meta` 독스트링 — *"`corp_name` + `rcept_dt` 접두만으로 후보가 1,469 → 1건이 되고 골든이 1위가 된다"*
- `tools.search_chunks` 독스트링(`tools.py:375`) — *"`corp_name` 만으로는 골든이 15/26 이지만 `rcept_dt` prefix 를 함께 걸면 1위가 된다"*
- `03 C-3` 표 — `corp_name` 1,469→26 · `rcept_dt` 26→1 · `path` 고유 8,636개

**정확한 문장으로 바꿔 적어야 한다:**

> 🔴 측정 불가인 것은 **"`A8` 안의 `A0` 구성요소"** 이고, **메타 필터 축(`corp_name`·`rcept_dt`·`path`)의
> 기여는 측정 가능하다.** 방법은 `_gather_meta` LOO 가 아니라 **도구 인자 LOO** 다 —
> `search_chunks`/`_search_sections` 에 그 축을 넘기지 않는 arm(`L6`~`L8`)을 세우면 된다.
> 우리가 못 한 것은 측정이 아니라 **표현 자리를 찾는 것**이었다.

**비용과 위험** — 🔴 근거가 바뀌므로 **캐시 전량 미적중 = 새 지출**이다. `A8-lean` 이 그리드 72
에 637.9원이었으므로 축당 **600~2,600원**(전체 88 기준)을 봐야 한다. 그리고 Δ 가 **크게 음수**로
나올 것이 거의 확실하다(위 세 실측) — 즉 **"쟀고 기여가 컸다"** 를 사는 측정이고, 성적을 올리는
arm 이 아니다. 🔴 **v4 의 우선순위에서는 낮다** (예산이 남을 때 `L6`(`corp_name`) 하나만 세워
"메타 축이 최대 기여" 를 주장에서 측정으로 바꾸는 것이 가장 값싸다).

### 🔴 이 라운드가 논문에서 실제로 산 것 — arm 이 아니라 **논거 넷**

우선순위와 별개로, **지출 0원에 제안서 `§7` 이 쓸 수 있는 독립 근거가 넷 생겼다.**

1. **PCST 기각을 원저자가 지지한다** — G-Retriever Appendix B.1 이 *"그래프가 컨텍스트에 들어가면
   `k=0` 으로 두어 전체 그래프를 그대로 반환한다"* 는 분기를 적어 뒀다. 우리 후보 풀 p50 = 2 가
   정확히 그 조건이다 (P2-22).
2. **A2(임베딩 Δ=0) 기각이 ToG-2 실측과 같다** — 엔티티 프루닝 도구 비교에서 **bi-encoder 임베딩이
   최악군**이고 BM25 가 그보다 낫다 (P6-110). Relink 도 같은 말을 −19.4% 로 적었다 (P8-157).
3. **"그래프는 대체가 아니라 가산 채널" 이 HyperGraphRAG 자신의 ablation 이다** — 하이퍼그래프
   **단독은 청크 RAG 단독에 진다** (R-S 53.6 vs 62.6) (P7-131). `03 C-3`(필터 축) 결정의 독립 근거.
4. **`ORACLE`·`A16` 회귀의 기전이 G-Retriever 에 실측으로 있다** — 걸러지지 않은 그래프 컨텍스트가
   frozen LLM 을 **질문만 준 것보다 나쁘게** 만든다 (61.16 → 41.06) (P2-26). *"회수보다 정밀도"*.

그리고 **naive 1-hop 확장이 해롭다**(P4-65: R@2 50.7→42.2)가 우리 `L3`(+0.0%p)·`_partner_quota`
실측 기각과 같은 결과여서, **다중 허브 결속을 세우지 않는 판단**을 논문이 지지한다.
