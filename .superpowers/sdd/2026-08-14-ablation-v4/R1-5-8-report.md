   다른 태스크가 처리해야 한다.
2. **`docs/proposal/technical-proposal.md`의 "도구 15종 function calling" 서술**
   (§4.6, 아키텍처 다이어그램 line 431, glossary line 159·196, 계보 line 2639·2645)도
   base.md와 같은 근본 결함(실행 경로에 `tools=` 미전달)을 반영하지 않은 채 "function
   calling"을 실행 중인 것처럼 서술한다. 이건 R1-5/R1-8이 명시적으로 지정한 "넷"에
   포함되지 않았고("이 태스크는 열 개 중 넷을 닫는다"), technical-proposal.md 안에서도
   §4.6은 실제로는 A5의 진짜 메커니즘(근거에 계산값을 미리 박아 넣는 것)을 뒤에 정확히
   설명하고 있어 완전히 틀린 것은 아니라 **일부러 손대지 않고 남겨뒀다**. 남은 여섯
   pair-defect 중 하나로 추정되니 사용자가 확인 바람.
3. **`src/argus/ablation.py:119`의 "계산 도구 14종"** 표기는 `tools.py`의 실측(계산
   7종, 검색 8종=15종 전체)과 어긋난다(`09-ablation.md:296`은 이미 7종으로 정정돼
