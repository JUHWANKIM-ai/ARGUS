## §2. 정규식 전/후

```python
# 전
_SCALE_ALT = "조원|천억원|백억원|억원|백만원|만원|천원|조|억|원"
_MONEY_RE  = re.compile(rf"(-?\d[\d,]*(?:\.\d+)?)\s*({_SCALE_ALT})")

# 후 — 순서가 정본이고, 표지 안에 **가로 공백만** 허용한다
_SCALE_UNITS = ("조원", "천억원", "백억원", "십억원", "억원",
                "백만원", "만원", "천원", "조", "억", "원")
_SCALE_SP    = "[ \t\u00a0]*"
_SCALE_ALT   = "|".join(_SCALE_SP.join(unit) for unit in _SCALE_UNITS)
```

**긴 표지 우선 규율을 깨지 않았다.** 순서를 `_SCALE_UNITS` 하나로 옮기고 그 순서를
그대로 이어 붙인다. `십억원` 은 `억원` **앞**, `천억원`·`백억원` 은 그보다 앞이다.
`tests/test_r3b_money_coverage.py::test_longer_markers_still_win_after_allowing_spaces`
가 `1,000백만 원 = 1e9` · `5천억 원 = 5e11` 로 그것을 고정한다.

**`\s*` 가 아니라 가로 공백만이다.** `\s` 로 넓히면 표에서 줄이 갈린 `1,000백만\n원` 이
하나의 금액이 되어 **없던 금액이 생긴다.**

**같은 목록이 세 곳에 있었다 — 하나로 모았다.**

| 자리 | 종전 | 후 |
|---|---|---|
| `critic._SCALE_ALT` | 붙임 10종 | **정본** (12종·공백 허용) |
| `critic._SCALE` | 배율 dict | 정본과 `assert` 로 묶었다 |
| `error_analysis._MONEY_RE` | 🔴 **별도 8종** (`천억원`·`백억원`·`십억원` 누락) | critic 을 가리킨다 |

🔴 종전 채점기는 `5천억원` 을 **어느 대안에도 못 걸어 무단위 `5`** 로 읽고 있었다.
