## 🔴 RF-1 — 없는 분기보고서를 물으면 **다른 분기 보고서로 답한다**

`AUD2-03` — *"현대건설의 **2026년 3분기** 분기보고서에 기재된 수주잔고는 얼마인가?"*

코퍼스는 **2026.03 접수분까지**라 2026년 3분기 보고서(2026-11 접수)는 **없다.**
그런데:

```
trace   filters=base_year=2026,doc_subtype=quarter … n=8
        ids=…20260515002899   ← 2026년 1분기 보고서다
answer  "현대건설의 2026년 3분기 분기보고서에 수주잔고가 기재되어 있지 않습니다.
         이는 기업공시서식 작성기준에 따라 …"
        (근거: [분기보고서 2026] 현대건설, 접수번호 20260515002899, …)
```

🔴 **거짓 전제를 받아들였다.** 없는 보고서를 있는 것처럼 말하고, **다른 보고서를 근거로
달았다.** §5 「근거 기반(Hallucination)」과 「정보한계 대응」에 함께 걸린다.

**원인은 정확히 좁혀진다.** [`router.missing_named_report`](../src/argus/agent/router.py#L220)
는 `doc_subtype` 과 `base_year`/`rcept_dt[:6]` 만 본다. *"2026년 3분기"* 는
`doc_subtype=quarter`·`base_year=2026` 으로 풀리고 **2026년 1분기 보고서가 그 조건을
만족**하므로 통과한다 — **몇 분기인지가 축에 없다.**

**대조군으로 확인했다.** *"현대건설의 2026년 **반기**보고서"* 는 `doc_subtype=half` 라
축이 갈려 **`NO_SUCH_REPORT` 로 정확히 잡힌다.** 즉 결함은 **분기 구분 하나**다.

- [ ] `_report_axes` 에 분기(1/2/3분기) 축을 더한다 — LLM 0회 · 크레딧 0원
