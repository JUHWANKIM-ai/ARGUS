## §0. A34 → A38 이 규약을 흔드는가 — **안 흔든다 (실측)**

```

```

🔴 **첫 시험은 나를 속였다.** `flags.use("A34")` 를 맨으로 불렀는데 그것은
컨텍스트 매니저라 아무 일도 안 한다 — A38 을 두 번 돌리고 "차이 없음" 이라 적을
뻔했다. `set_arm` 으로 고치고 `assert flags.current().name == "A34"` 를 박았다.
지금 수치는 그 단언이 통과한 판이다.

```

수치는 살아남았다 — 갈린 15건 중 14건이 기대 수치를 전건 싣는다. 하나(`AUD2-12`)만

### ③ `근거 표시` 측정 규칙이 낱말 하나를 요구했다 — **고쳤다**

**→ 고침.** 아래가 처음 적었던 진단이고, *"동결이 가까워 안 고친다"* 고 썼는데
그것은 핑계였다 — 같은 재측정을 이날 이미 세 번 했고 두 번은 0원이었다.

```
CITATION_RE  근거\s*:.*?(?:접수번호\s*)?\d{14}      ← 낱말을 선택으로 바꿨다
```

규약 `R2` 가 요구하는 것은 *"근거 공시를 표시(공시명·공시일)"* 이지 **`접수번호` 라는
낱말이 아니다.** 낱말을 요구하는 것은 우리 §7.5 문안 취향을 규약 검사로 쓰는 것이었다.

측정 (세 코호트 재실행):

```
정답        110/112 -> 110/112      안 움직였다
표기 집계   90/112 -> 94/112
LLM 호출    132회 -> 106회 (-26)    full 코호트
토큰        393,981 -> 367,500      -185.9원/판
```

🔴 **얻은 것은 정확도가 아니라 비용과 정직함이다.** 4건이라 봤던 것이 실제로는 26회였다 —
`quick_check` 는 `attach_citation` 이 결정적 표기를 붙이기 **전**에 돌아서, 모델 자신의
문안이 라벨을 빠뜨린 만큼 전부 헛된 critic 호출이 됐다.

<details><summary>처음 적었던 진단 (기록)</summary>

`CITATION_RE = 근거\s*:.*?접수번호\s*\d{14}` 가 **"접수번호" 라는 낱말을 요구한다.**
모델이 `(근거: …, 2024-11-14, 20241114000001)` 처럼 낱말 없이 14자리만 적으면
표기가 있는데도 없다고 세어진다 — `Q-030`·`Q-052`·`Q-087`·`Q-101` 4건(112 중 3.6%).

**손실은 정확도가 아니라 비용과 각주다**: 표기가 없다고 판정되면 critic 이 한 번 더
불리고, 그 판정이 각주로 나간다. 위 ② 의 고침으로 각주는 이제 *"근거 표기가 없습니다"*
라고 정확히 말하지만, **그 말 자체가 이 4건에서는 틀렸다.**

동결 8일 전이라 안 고친다 — 규칙을 느슨하게 하면 critic 호출이 줄어 답변이 바뀌고,
110/112 를 다시 세워야 한다. **다음 세대의 과제로 남긴다.**

</details>

### ⑨ 🔴 로컬 검증이 서버 동작을 보장하지 않는다 (미해결 · 오늘 실제로 걸렸다)

로컬 측정은 `RequestCache` 를 붙여 **저장된 응답을 재생**한다. 프롬프트가 바이트 동일이면
캐시가 적중하므로 재측정이 사실상 공짜인데, 그 대가로 **생성 자체를 검증하지 않는다.**

2026-08-17 에 이것이 오답 판정을 뒤집었다:

```
H-008  로컬 (캐시 재생)   골든 646,244,000,000 실림  ->  해결로 보고
       서버 (생짜 생성)   집계 줄을 무시하고 자기 서사  ->  실패
```

집계 줄은 근거에 정확히 실려 있었고, 로컬에서 통과한 응답은 **다른 조건에서 만들어진 것**
이었다. 서버에 올려 찔러 보고서야 알았다.

**막을 장치가 없다.** 자동화 시험 1,409건은 결정적 경로만 덮고 생성은 안 부른다. 캐시를
끄고 로컬에서 돌리면 생성을 검증하지만 그 순간 비용이 발생하고, 그렇게 잰 값도 아래 ⑩
때문에 회차마다 달라진다.

**현재 운용 규칙**: 판정 근거는 **서버 실측**으로만 삼는다. 로컬 캐시 결과는 회귀 감시용
이지 합격 판정용이 아니다. 이 규칙은 문서에만 있고 코드가 강제하지 않는다.
