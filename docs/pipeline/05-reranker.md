## E-3. 지표

Recall@5 는 **유지**되어야 하고(리랭커는 리콜을 못 늘린다), **MRR · Precision@1 개선폭**만 본다.

```
Δ MRR        = MRR(A3) - MRR(A2)
Δ P@1        = P@1(A3) - P@1(A2)
지연 비용    = 리랭킹 추가 시간 (ms)
```
