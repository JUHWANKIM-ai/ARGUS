### 🔴 E-2b. 이 후보 표에 **CLOVA 자체 리랭커가 빠져 있었다** (2026-08-11 발견)

CLOVA Studio 사용량 대시보드의 모델 구분에 **`리랭커`** 가 1급 API 로 있다. 위 표는
후보를 **전부 외부 모델**(BGE·MiniLM)로만 세웠고, 그래서 E-1 의 규정 리스크가 이 Phase
전체를 막았다.

**그 리스크는 CLOVA 자체 리랭커에는 걸리지 않는다.** "외 LLM 사용 시 평가대상에서 제외"
가 금지하는 것은 HyperCLOVA X 밖의 모델이고, CLOVA Studio 가 제공하는 리랭커는 같은
플랫폼이다. **즉 규정 때문에 못 한 것이 아니라, 규정에 안 걸리는 경로를 후보에 넣지
않아서 못 한 것이다.**

같은 누락이 세 개 더 있다 — 대시보드가 제공하는 것과 우리가 손으로 만든 것의 대조:

| CLOVA 1급 API | 우리 구현 | 상태 |
|---|---|---|
| **리랭커** | 없음 (BM25 단독) | 재본 적 없음 |
| **라우터** | `src/argus/agent/router.py` — 정규식 | 이번 라운드에 **오탐 6종** 나왔다 |
| **문단 나누기** | 우리 청킹 (`corpus/markdown.py`·`sections.py`) | 재본 적 없음 |
| **RAG Reasoning** | 우리 ReAct 사다리 (`pipeline.plan_hops`) | 재본 적 없음 |
| 임베딩 V2 | `embed.py` (bge-m3) | ✅ 재고 **기각**했다 (A2 — dense 가 top_k 에 31건 올렸으나 골든 0건) |

**임베딩만 실제로 재고 기각했고 나머지 넷은 재본 적이 없다.** A2 를 잰 것이 옳은 절차였고,
그 절차를 넷에는 적용하지 않았다.

> 🔴 **다만 "쓸 수 있다" 와 "쓸 이유가 있다" 는 다르다.** E-4 가 재검토 문턱 3축을 다시
> 재서 **전부 0** 이다. 리랭커를 지금 넣어도 **겨냥할 실패가 없어 Δ 를 잴 대상이 없다.**
> 이 발견은 규정 판정의 정정이고, 채택 근거가 아니다. 트랙은 열되 순서는 **측정이 먼저**다
> ([Ablation v3 계획](../superpowers/plans/2026-08-12-ablation-v3.md)).
>
> 🔴 **E-4 의 "겨냥 0" 은 그리드에서만 잰 값이다 (2026-08-12 한정 추가).** 세 축
> (`new_sector_retrieval` · A3 겨냥 문항 · 그리드 `RANKING`) 이 전부 **그리드 72문항**의
> 집계다. **밸류체인 코호트에서는 잰 적이 없고, 거기에 A8 이 못 회수한 골든 근거가
> 18건(46 − 28) 있다.** 그중 "후보엔 올랐는데 프롬프트에서 밀린" 갈래가 있으면 **그것이
> 리랭커의 겨냥이다.** v3 `T5-a` 가 18건을 갈래로 가른 뒤에 이 게이트를 다시 판정한다 —
> **그때까지 `A3` 를 "겨냥 없음" 으로 최종 기각하지 마라.**

## E-3. 지표

Recall@5 는 **유지**되어야 하고(리랭커는 리콜을 못 늘린다), **MRR · Precision@1 개선폭**만 본다.

```
Δ MRR        = MRR(A3) - MRR(A2)
Δ P@1        = P@1(A3) - P@1(A2)
지연 비용    = 리랭킹 추가 시간 (ms)
```
