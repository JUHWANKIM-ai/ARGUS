## E-1. 규정 리스크가 선행조건이다

| 문서 | 내용 |
|---|---|
| 과제소개자료 p.4 | "LLM은 HyperCLOVA X만 사용 가능. 외 LLM 사용 시 **평가대상에서 제외**" |
| 설명회 Q&A 12 | "최종답변 생성에서 LLM은 하이퍼클로바로 제안, **전체 서비스에서 하이퍼클로바만 사용해야 하는 건 아님**" |
| 전사본 28:07 | 검색 레이어·분류기에 별도 모델 학습·사용 **가능** |

리랭커(BGE-Reranker 등)는 **생성 모델이 아니라 랭킹 모델**이라 Q&A 12 해석상 허용에 가깝지만,
**실격이 걸린 항목**이라 확정 없이 공수를 넣지 않는다.

**대응**: Ablation 에서 A3 를 **독립 arm** 으로 두어, 미확정 시 통째로 뺀 곡선도 성립하게 한다.

## E-3. 지표

Recall@5 는 **유지**되어야 하고(리랭커는 리콜을 못 늘린다), **MRR · Precision@1 개선폭**만 본다.

```
Δ MRR        = MRR(A3) - MRR(A2)
Δ P@1        = P@1(A3) - P@1(A2)
지연 비용    = 리랭킹 추가 시간 (ms)
```
