## A-1. 문서 구조 프로파일

| 측정 | 방법 | 왜 필요한가 |
|---|---|---|
| 문서 길이 분포 | 유형×서식별 텍스트 길이 히스토그램 | chunk 크기 결정 ([04](04-retriever.md)) |
| **표 비율** | `<table>` 수 · 표 문자 / 전체 문자 | 표 분리 여부 (policy §8) |
| **숫자 비율** | 숫자 토큰 / 전체 토큰 | BM25 vs 임베딩 적합성 |
| 시간 정보 | 날짜 패턴 출현 위치·밀도 | 기간 필터 설계 근거 |
| 섹션 목차 깊이 | `periodic` 목차 트리 depth·노드 수 | 섹션 청킹 ([04](04-retriever.md)) |
| **라벨 어휘 사전** | 표 라벨 셀의 빈도 사전 (서식별) | 규칙 파싱 확장 여지 판정 |

**산출물** `artifacts/eda/doc_profile.json` · `notebooks/eda_documents.ipynb`

### 이미 확인된 것 (재검증만)

- periodic 680MB(95%) · holding 25MB · exchange 5MB · major 4MB
- 파일은 UTF-8 인데 `<meta charset=euc-kr>` — 자동 탐지 금지
- exchange 1,469건 중 계약 서식 1,126건(77%)
- 거래소공시는 커스텀 XML 이 아니라 **HTML 표**

### 반드시 새로 재야 하는 것

**`schema_matched=False` 343건의 라벨 분포.** 현재 상태:

| doc_subtype | n | amount | counterparty | period_start |
|---|---|---|---|---|
| 단일판매공급계약체결 | 1,106 | 1,047 | 1,078 | 987 |
| 투자판단관련주요경영사항 | 300 | **8** | **27** | **0** |
| 신규시설투자등 | 43 | **0** | **0** | 41 |

투자판단·신규시설투자는 금액이 자유 서술문 안에 있다(`"2. 투자 금액: 5.9조원"`).
**어떤 라벨 패턴을 몇 건이나 놓쳤는지 세면 규칙으로 건질 분량이 나온다.**
LLM 추출은 그러고도 안 되는 것에만 쓴다.

## A-2. 관계 구조 프로파일 — policy §1·§2

| 측정 | 방법 |
|---|---|
| **정정 체인** | 길이 분포, 최장 체인, 코퍼스 밖 참조 비율 (현재 45.5%) |
| **문서 간 참조** | `※ 관련공시` 행 파싱 — 실재 확인됨 |
| **기업 간 관계** | `counterparty` 가 universe 70개사에 있는 비율 |
| 연속 공시 구조 | 기업×분기 공시 밀도, 정기공시 제출 주기 |
| 섹터 응집도 | 같은 섹터 기업이 계약상대로 등장하는 빈도 |

**산출물** `artifacts/eda/relation_profile.json`

### 이 단계가 GraphRAG 채택을 결정한다

policy §2는 *"공시는 관계형 데이터라 GraphRAG와 잘 맞는다"* 를 **전제로 깐다.**
그 전제가 **우리 코퍼스에서 실제로 성립하는지** 여기서 검증한다.

```
기업-기업 엣지 밀도 = counterparty 가 universe 70개사인 건수 / 전체 계약 건수
```

| 판정 | 다음 행동 |
|---|---|
| 밀도 높음 | [03-graph-schema](03-graph-schema.md) 전면 진행, GraphRAG 채택 |
| 밀도 낮음 | 기업-기업 엣지 포기. **기업-공시-이벤트** 2부 그래프 + 하이브리드 검색으로 선회 |

> 실제 표본을 보면 계약상대가 `"글로벌 대형기업"`(비실명), `"Hyundai Electric America Corporation"`(해외 자회사)
> 처럼 universe 밖인 경우가 많다. **밀도가 낮게 나올 가능성을 미리 열어둔다.**

## A-3. 질의 가능성 매핑

CONVENTION §6 의 평가 질의 6종이 **어느 doc_group · 어느 필드에서 답이 나오는지** 역매핑한다.
답이 나올 수 없는 유형이 있으면 그게 곧 인덱싱 우선순위다.

현재 알려진 공백: **정기공시 질의는 근거 0건** (`periodic_sections.jsonl` 부재).
