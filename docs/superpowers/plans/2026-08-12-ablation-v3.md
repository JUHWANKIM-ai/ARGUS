# §1b. 🔴 v3 의 arm 구조 — **이 절이 이 문서의 중심이다**

## 사다리

```
A0 → A1 → A1b → [A3 ★신설] → A4 → A5 → A6 → A7 → A8
                 리랭커
```

| arm | v2 상태 | v3 |
|---|---|---|
| `A0`~`A1b`·`A4`~`A8` | 실측 완료 | **불변.** 캐시가 살아 있으면 재결제 없다 |
| `A2` 임베딩 | 측정 후 **기각** | 되살리지 않는다 (dense top_k 31건 중 골든 0건) |
| **`A3` 리랭커** | **보류** — 외부 모델(BGE)만 후보라 G1 에 막혔다 | ★ **CLOVA 리랭커로 신설.** 자리는 `A1b` 다음 |

## 변형 — **사다리가 아니라 같은 자리에서 갈아 끼우는 것**

| 변형 | 무엇을 바꾸나 | 🔴 위험 |
|---|---|---|
| **`A1b-clova`** | `A1b` 안의 라우터: 정규식 → CLOVA 라우터 | 🔴 **이기면 `A1b` 를 바꾸는 것이고, 그러면 그 위 전 arm 재측정이 붙는다** — `T3 문단나누기`를 이 라운드에서 뺀 것과 **같은 등급의 위험**이다 |
| **`A4-rr`** | `A4` 의 ReAct 사다리 → RAG Reasoning | 🔴 **G1 관문.** 추론/생성이라 답변 경로다. HCX 로 도는지 확정 못 하면 **착수 금지** |

**변형은 사다리에 끼우지 않는다.** 같은 위치의 head-to-head 로 재고, 이긴 쪽으로 갈아탄
뒤에 위쪽을 다시 돈다. **사다리 arm 과 섞어 적으면 Δ 의 의미가 사라진다.**

## 🔴 LOO 확장 — GraphRAG 판정을 **네 축으로 닫는다**

`(A)` 목표의 실체가 이 표다. 지금 그래프에 대해 우리가 가진 실측은 **L1·L3 둘뿐**이고,
**골격과 `REFERS_TO` 는 한 번도 안 쟀다.**

| LOO | 뺀 것 | 상태 | 값 |
|---|---|---|---|
| `L1` | 정정체인 hop (550엣지 순회) | 실측 | **−9.7%p** (62→55/72) · 근거 112→**98** |
| `L2` | major·holding 필드 (n-ary 노드 속성) | 실측 | **−15.3%p** — 최대 병목 |
| `L3` | 발주처 2-hop (`≡ A7`) | 실측 | **+0.0%p** |
| **`L4`** | **관련공시 `REFERS_TO` hop** (910건 / 1,267엣지) | ★ **신설** | **없다 — 안 쟀다** |
| **`L5`** | **2부 그래프 메타 축** (`corp_name`·`rcept_dt`·`doc_subtype`·`path`) | ★ **신설** | **없다 — 안 쟀다** |

### 🔴 L4 는 착수 전에 갈래를 확인한다 (5분 · 0원)

`REFERS_TO` 를 **질의 시점에 순회하는 코드가 있는지**부터 본다
(`src/argus/agent/` 에서 `references` 사용처). 두 갈래다:

- **순회한다** → `L4 = A8 − REFERES_TO hop` (LOO). 그대로 잰다.
- **순회하지 않는다** → 뺄 것이 없다. 그러면 **`A9 = + REFERS_TO hop` 신설 arm** 이다.
  🔴 **이쪽이면 발견이다** — 1,267엣지를 만들어 놓고 **검색에 쓰지 않고 있다는 뜻**이고,
  "해지 20건 전건이 원계약을 명시한다"는 서술이 **파이프라인에 반영 안 된 것**이다.

### 🔴 L5 는 "못 잰다" 가 정당한 결론이다

`09-ablation §I-5e` 가 *"`uses_bm25=False` 에서만 도달하므로 **A8 안에 떼어낼 `A0`
구성요소가 없다**"* 고 적어 뒀다. 메타 축이 플래그로 떼어지지 않으면 **L5 는 불가**다.
**그때는 억지로 만들지 말고 "골격의 Δ 는 구조적으로 측정 불가" 를 명시적 결론으로 남긴다.**
지금 제안서가 `A1b +41.7%p` 를 골격의 값처럼 읽힐 수 있게 쓰는 것이 더 나쁘다.

### 판정 규칙 — 이걸로 GraphRAG 를 닫는다

| 결과 | 판정 |
|---|---|
| `L1` 재현 + `L4` 유의 | ✅ **채택 확정.** 공시—공시 엣지가 두 종류 다 번다 |
| `L1` 만 유의, `L4` ≈ 0 | 🟡 **부분 채택** — 정정 체인만. `REFERS_TO` 는 색인 비용만 쓰는 것 |
| `L3` 이 밸류체인에서도 0 (T5-a 가 (i) 다수) | ❌ **계약상대 2-hop 기각 확정** |
| `L5` 불가 | 📝 **측정 불가를 결론으로 기록** — 추정값을 쓰지 않는다 |

## 🔴 v3 에는 heldout 이 없다

`heldout.jsonl` 은 **2회 소진**(v1 `A6` · v2 `A8`)이고 3회째는
`scripts/ablation.py::assert_heldout_unused` 가 세 겹으로 막는다. **v3 의 일반화 측정은
회귀 10 + 밸류체인 12 뿐이고, 그 둘의 한계는 09-ablation 이 이미 적어 뒀다** —
*"회귀 10 은 이미 본 실패의 재현이고 밸류체인 12 는 한 기능의 측정"*.

**즉 v3 는 일반화 주장을 못 하는 판이다.** 새 heldout 18문항은 **08-25 동결 후**이므로
v3 의 결론은 dev 위에서만 성립한다 — **제안서에 그렇게 쓴다.**

# Phase 1b — 🔴 그래프 2-hop 재검토를 **닫는다** (T5)

## 🔴 먼저 범위를 못박는다 — 그래프는 **기각된 것이 아니다**

**"GraphRAG 기각" 은 엣지 하나에 대한 판정이다.** 기각한 것은 `기업 —계약했다→ 기업`
직접 엣지(29쌍 · 완결도 1.2%)와 커뮤니티 탐지뿐이고, **노드·엣지를 코퍼스에 맞게
재정의한 쪽은 우리 성적의 대부분을 만든다** — 아래 셋 다 두 판에서 재현된 실측이다.

| 재정의한 것 | 실측 기여 | 기전 |
|---|---|---|
| `공시 —정정한다→ 공시` 550엣지 **순회** | **L1 = −9.7%p** (62→55/72) | 근거도 112→**98** 동반 하락 = **검색이 못 찾는다** |
| **n-ary 이벤트 노드** 속성 (major·holding) | **L2 = −15.3%p** (62→51/72) | **최대 병목.** 근거 112 그대로인데 정답 11건 적다 = 생성이 못 쓴다 |
| 2부 그래프를 **탐색 아니라 메타 축으로** | **A1→A1b = +41.7%p** | 사다리 최대 전이. `doc_subtype` 문서군별 색인 |
| `기업 —(계약상대)— 기업` **2-hop** | 🟡 그리드 **+0.0%p** | **T5 가 겨냥하는 것은 이것 하나다** |

**T5 는 그래프의 채택 여부를 다시 묻는 태스크가 아니다.** 그것은 이미 위 세 줄로 답이 났다.
T5 가 묻는 것은 **네 번째 줄, 유일하게 미확정인 엣지 하나**다.
