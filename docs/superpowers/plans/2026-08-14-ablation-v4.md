## `T1` 의 갈래 셋 — 🔴 **고르는 기준은 비용이 아니라 효과다**

사용자 판단(2026-08-14): **예산은 제약이 아니다.** 그래서 아래 비용은 *참고값*이고,

| 갈래 | 입력 | 참고 비용 | 🔴 효과 판정 |
|---|---|---|---|

| **T1-md** — 우리 마크다운 전량 | 0.44~0.63M 토큰 | 7,500~9,000원 | 🔴 **선택하지 않는다.** 이미 파싱된 필드를 LLM 으로 다시 뽑는 것이다 — 정의상 새 정보가 없다 |
| **T1-targeted** — `schema_matched=False` **238건**의 **원문** | 238건 | 수백~수천원 | 🟢 **규칙이 못 뽑은 것만** 뽑는다. 겨냥이 실측으로 확인된 유일한 갈래 |

```

```

🔴 **`T1` 의 정보 이득은 "규칙이 못 파싱한 238건" 에만 있다.** 나머지 1,829건은 규칙이 이미

**Δ 가 0 이어서** 안 한다. `L2`(노드 속성) LOO 가 −15.3%p 를 낸 것은 **그 속성이 이미 있어서**다.

그리고 v3 가 그 238건에 대해 이미 하나를 쟀다 — `R2-C` 실측: **그리드 88 의 근거 208건 중

## 🔴 `A10` 에 대해 — 예산이 아닌 이유가 하나 남아 있다

v3 는 `A10` 을 **두 이유**로 보류했다:

```
① 겨냥 5건 전부를 우리 결정적 검사가 이미 잡고 있어         ← 🔴 이 이유는 남아 있다
   0원 대안(검사 발화 → 재생성 1회)이 같은 겨냥을 갖는다
② 캐시 키에 temperature 가 있어 k=3 은 재실행마다 전액 재결제  ← 사라졌다
```

> **② API 키를 재발급해 `.env` 에 반영했다.** 채팅에 노출된 두 키(v3 이전)는 이제 죽었다.
> 🔴 **에이전트는 `.env` 를 읽지 않으므로 검증하지 않는다** — 사용자 확인으로 닫는다.
> 🔴 **캐시는 무효화되지 않는다** — `RequestCache` 가 `(url, body)` 의 SHA256 으로만 키를
> 만들고 API 키는 키에 들어가지 않는다. 따라서 v3 의 캐시 적중은 그대로 유지되고,
> **재측정 비용이 늘지 않는다.**
