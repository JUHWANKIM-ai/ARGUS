# §1. 서비스 정의

> ## 공시 하나를 읽는 게 아니라, **공시들 사이의 관계를 읽는다.**

DART 에서 사람이 직접 하기 어려운 셋을 대신한다:

| | 사용자의 질문 | 왜 어려운가 |
|---|---|---|
| ① | **이 공시, 나중에 바뀌었나?** | 🔴 DART 에서 원공시만 보면 정정 여부를 알 수 없다 |
| ② | **이 회사는 누구와 거래하나?** | 계약 상대가 공시마다 흩어져 있다 |
| ③ | **이 회사 최근 움직임이 뭔가?** | 공시 수십 건을 다 열어야 한다 |

## 🔴 정직성이 기능이다

우리 데이터에는 한계가 있다 — **70개사만 · 계약상대 표기 흔들림 · 관계망 완결도 낮음.**
**숨기지 않고 화면에 표시한다.** *"근거 없는 답은 하지 않습니다"* 가 ARGUS 의 정체성이고
**그것이 다른 공시 서비스와 다른 점**이다.

## 버린 대안 — 공시 원문 뷰어

DART 링크를 걸어 주는 것. **DART 가 이미 하고 우리가 더할 게 없다.**
**관계를 읽어 주는 것**만 우리가 할 수 있다.

## §4.1 랜딩 `/`

```
              누가 누구에게서 일을 받는가

      [ 기업 검색 ▸ 삼성전자 · 현대건설 · 셀트리온 … ]

                 ┌── 한화오션
      방위사업청 ─┼── 한화에어로스페이스        원 크기 = 계약 건수

                 └── 현대로템                  클릭 → 해당 페이지

      한국수력원자력 ── 두산에너빌리티 · 삼성물산 …
       35건

      🔴 공시 10건 중 4건이 나중에 정정됩니다      → [정정된 공시 보기]
```

**한 화면에 서비스가 다 보인다** — 관계망(무엇을) · 검색(어떻게) · 정정 훅(왜).

🔴 **그래프 라이브러리를 쓰지 않는다.** 145 노드 · 44 쌍이라 **SVG 로 직접 그린다.**
예시의 `WorldStatusMap` 이 같은 방식이다. 레이아웃은 **허브 방사형**(hub-and-spoke) —
발주처를 중심에 두고 파트너를 원주에 배치한다. 힘 기반 시뮬레이션은 쓰지 않는다.

**렌더 대상**: `count >= 5` 인 허브만(상위 약 10개). 나머지는 `/network` 에서 본다.

## 🔴 보안 — 첫 판의 게이트를 상속한다

`scripts/build_site.py` 가 만든 게이트 여섯을 **새 스크립트가 그대로 가져간다**:

```
① evalset/ 을 읽지 않는다          🔴 골든셋·heldout 은 서비스와 무관하다
② src/argus 를 import 하지 않는다   .env 경로가 그쪽에 있다
③ 공인 IP 를 발행하지 않는다
④ 코퍼스 원문을 재배포하지 않는다     공시 필드만 쓴다
⑤ 출력 필드 화이트리스트            🔴 모르는 필드가 붙으면 빌드가 죽는다
⑥ 게이트 발화를 테스트로 고정
```

🔴 **`evalset/` 차단이 특히 중요하다.** 첫 판은 `report.json` 을 읽어 평가셋 정보가 새는 것을
막느라 화이트리스트를 짰다. **이번 판은 그 파일을 아예 안 읽는다** — 서비스 데이터는
공시 원본에서만 온다.

### 🔴 §5b. 코드에는 있었는데 위 여섯 줄에 없던 것 (2026-08-16 · Task 1 Step 1)

`build_site.py` 를 지우기 전에 읽어 대조했다. **위 여섯은 게이트의 *목록*이지 *구현*이
아니었다.** 지우면 사라지는 설계가 아래 열하나다. 새 스크립트가 상속할 것과 **의도적으로
뒤집을 것**을 함께 적는다.

| | 구현 | 어디에 있었나 | v2 |
|---|---|---|---|
| **a** | **읽기 게이트가 함수 층에 있다** — 문서가 아니라 코드가 막는다. 금지 토큰 `heldout`·`data/`·`.env`·`src/`·`secrets`·`attic` 의 **부분 문자열** 검사 + 저장소 밖 경로 거부(`resolve()` 후 `ROOT` 하위인지) | `FORBIDDEN_PATHS` · `_guard_path()` | 🔴 **뒤집어 짰다 — 금지 목록이 아니라 *허용 목록*이다.** 두 이유. ① v2 는 `data/…/universe.csv` 를 **읽어야** 해서(70개사 정본) `data/` 를 통째로 막을 수 없다. ② 🔴 **금지 대상의 이름을 소스에 적는 것 자체가 금지다** — 계획서의 테스트가 빌드 스크립트 소스에서 `evalset`·`ablation`·`heldout` 문자열을 찾는다. 허용 목록은 두 제약을 풀면서 **더 강하다**: `ALLOWED_READS` 의 **여섯 파일** 밖으로는 어떤 경로도 열리지 않고, 다음 세대가 원천을 늘려도 조용히 새지 않는다 |
| **b** | **출력 비밀 패턴 스캔** — `nv-` · `sk-` · `Bearer …` · `X-NCP-*` · `CLOVA_API_KEY|CLOVA_STUDIO_API_KEY` · **40자 이상 영숫자 덩어리**. ②(import 금지)와 **독립된 두 번째 층**이다 | `SECRET_PATTERNS` | 상속 |
| **c** | **`heldout` 은 `evalset` 과 별개 토큰족** — `heldout`·`held-out`·`held_out` 셋을 본다. 게다가 정본에서 읽은 **모든 문장**이 `redact_reserved()` 를 지나 `[비공개 평가 트랙]` 으로 치환된다(원장 행을 빼면 검산이 깨져서 **금액은 남기고 이름만** 지웠다) | `HELDOUT_TOKENS` · `redact_reserved()` | 상속 (v2 는 정본 문서를 안 읽으므로 치환은 불필요) |
| **d** | 🔴 **14자리 문서 식별자 차단** — 출력의 어떤 14자리 연속 숫자도 `SiteLeak`. DART 접수번호가 골든 근거를 지목하기 때문이었다 | `DOC_ID` · `test_no_output_carries_a_document_identifier` | 🔴 **의도적으로 뒤집는다.** v2 의 `rcept_no` 가 바로 그 14자리이고 **정정 체인(`targets`)이 접수번호 목록**이다. 근거가 달라서다 — v1 의 접수번호는 *평가셋 골든*에서 왔고 v2 의 것은 *공시 원본*에서 온다. **이 문단이 그 판단의 기록이다.** 다음 세대가 게이트를 조용히 지우거나 되살려 빌드를 깨지 않게 |
| **e** | **화이트리스트는 3분법이다** — `ALLOWED` / `BLOCKED` / `KNOWN = ALLOWED\|BLOCKED`. 셋 다 아닌 필드는 **판단이 필요하다는 뜻이라 죽인다.** ⑤ 는 이 중 앞의 하나만 적고 있었다 | `ROW_FIELDS_*` · `project_row()` | 상속 — **차단 목록에 *사유*를 함께 적는 것**이 이 설계의 절반이다 |
| **f** | **같은 이름의 스칼라 집계는 통과시킨다** — 차단 필드와 이름이 같아도 `int`/`float` 이면 이름을 바꿔(`golden→goldenDenominator`) 싣고, 문자열·목록·딕셔너리면 죽인다. **게이트를 무디게 두고 예외를 좁게** 판 것 | `sanitize_aggregate()` · `AGGREGATE_RENAME` | v2 에 해당 없음 (집계를 옮겨 오지 않는다) |
| **g** | **자유 서술의 금액 마스킹** — 4자리 이상 수를 `[금액]` 으로. **연도(1900~2100)는 남긴다.** 마스킹을 끄면 게이트가 발화하는 것을 테스트가 고정했다 = 장식이 아니었다 | `_mask_amounts()` | v2 에 자유 서술 필드가 없으면 불필요. 🔴 **생기면 되살려라** |
| **h** | **공인 IP 를 코드에도 테스트에도 적지 않는다** — `deploy/README.md` 에서 **뽑아** 대조한다. ③ 은 "발행하지 않는다" 만 적고 *"그러니 어디에도 적지 마라"* 를 안 적었다 | `public_ips()` | 상속 |
| **i** | **게이트는 쓰기 *전에* 전량을 훑는다** — 하나라도 걸리면 **아무 파일도 쓰이지 않는다.** 반쯤 쓰인 산출물이 남지 않는 것이 설계였다 | `gate_all()` → `build_site()` | 상속 |
| **j** | **발화 증명이 빌더에 딸려 있다** — `--prove-gates` 가 일부러 위반 페이로드를 넣어 여섯이 다 죽는지 본다. 테스트는 그 목록을 `parametrize` 로 받는다 → **프로브가 게이트와 따로 낡을 수 없다.** ⑥ 은 "테스트로 고정" 까지만 적었다 | `gate_probes()` · `prove_gates()` | 상속 |
| **k** | **평가셋 프로브는 전문 + 앞 20자 둘 다** — 잘려 실린 유출을 전문 검사만으로는 못 잡는다 | `PROBE_PREFIX = 20` | v2 는 evalset 을 **안 읽으므로** 프로브 자체가 없다. 🔴 **안 읽는 것이 프로브보다 강한 보장이다** |

🔴 **`CORPUS_TOKENS` 에 `universe.csv` 가 있었다.** v2 는 그 파일을 읽지만 **출력에 그
이름을 쓰지 않으면** 규율은 지켜진다 — `dart-disclosures`·`periodic_sections.txt` 도 같다.
**읽기 금지와 출력 금지는 다른 게이트다.** v1 은 `data/` 를 둘 다 막아 구분이 필요 없었다.

## 저장소 규율

```
site/node_modules  🔴 절대 커밋하지 않는다 — 제출물 1번(소스코드)에 섞이면 안 된다

```
