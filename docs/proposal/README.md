## 2. CONVENTION §9 요건 대응

주최 측 요구: *제안 요약 · 문제 정의 · 제안 방법 · 시스템 구성도 · 주요 기능 흐름도 ·
사용자 시나리오 · 기대효과·확장성* — **자유 양식** (설명회 Q&A 6).

| 요구 항목 | 본문 절 | 충족 |
|---|---|---|
| 제안 요약 | §1 | ✅ 성능·비용·주장 3축 |
| 문제 정의 | §2 | ✅ 도메인 난점 4종 전부 실측 근거 |
| 제안 방법 | §3 · §4 | ✅ 데이터 분석 → 구성요소 6종 |
| 시스템 구성도 | §4.1 | ✅ 오프라인/온라인 2도. 원본 `docs/figures/argus-algorithm-v2.drawio` |
| 주요 기능 흐름도 | §4.2 | ✅ 질의 1건의 생애 |
| 사용자 시나리오 | §8 | ✅ 4종 (단순조회 · 다지점비교 · 정정추적 · 정보한계) — **전부 실제 골든셋 문항** |
| 기대효과·확장성 | §10 | ✅ 운영 지표 + 확장 경로 5종 + 방법론 이식성 |

**요건 대비 빠진 항목 없음.** 형식 요구(분량·서식)는 ✅ **제한이 없음이 확정됐다** —
*"기술제안서에는 분량, 양식에 제한이 없습니다"* (2026-08-12 주최측 답변 #12 ·
[`../organizer-qa.md`](../organizer-qa.md)). 자유 양식으로 처리한 판단이 확인됐고,
**SSOT 를 길게 옮겨도 된다.**

추가로 넣은 것 — 평가 설계(§5) · Ablation(§6) · **채택하지 않은 것**(§7) ·
규정 준수(§9) · 한계(§11) · 부록 A~D.
