[`../organizer-qa.md`](../organizer-qa.md)). 자유 양식으로 처리한 판단이 확인됐고,
**SSOT 를 길게 옮겨도 된다.**

추가로 넣은 것 — 평가 설계(§5) · Ablation(§6) · **채택하지 않은 것**(§7) ·

## 6. 이 문서를 쓰면서 지킨 것

- **CLOVA API 호출 0회.** `argus.clova` 를 import 하지 않았다.
- **`.env` 를 열지 않았다.** API 키·서버 IP·비밀번호를 어디에도 쓰지 않았다.
- **수정한 파일은 `docs/proposal/README.md` 와 저장소 루트 `README.md` 둘뿐이다**
  (제출물 3번의 기재 위치가 루트 `README.md` 로 못박혔기 때문이다). 나머지는 전부 읽기만 했다.
- **모든 수치에 출처 태그를 달았다.** 기억이나 추정으로 쓴 수치는 없다.
- **측정하지 않은 것을 측정한 것처럼 쓰지 않았다.** heldout 1회 · A2 정답률 미측정 ·
  A3 미착수를 본문에 명시했다.
