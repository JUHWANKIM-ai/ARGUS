## 남은 불확실

**증명하지 못했다.** 서버 로그를 못 읽었다 — NCP 는 인증키로 **콘솔에서 비밀번호를 조회**하는
방식이라(CONVENTION §8) `.pem` 만으로는 SSH 로그인이 안 된다
(`Permission denied (publickey,password)`). 다만 그 거절 응답 자체가 **차단 해제 후에는 SSH 데몬이
살아 있었다**는 증거다.

**확정 방법** — 콘솔에서 비밀번호를 조회해 접속한 뒤:

```bash
uptime                              # 재부팅 흔적이 없으면 차단설 확정
systemctl show argus -p NRestarts   # 재시작 0 이면 앱은 죽지 않았다
dmesg -T | grep -i "oom\|kill"      # OOM 흔적
tail -100 /var/log/argus.log        # 그 시각 요청이 도달했는지
```

**재부팅·재시작 흔적이 나오면 이 판정을 뒤집어야 한다.**
